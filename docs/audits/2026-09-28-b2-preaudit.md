## 4. Gateway design (task 4)

Conform to D-012 / D-013 / D-019 / D-023 / D-024 / architecture TARGET L247–261 / amendment §2.4.

### Package layout (`src/opspilot/llm/`)

```text
llm/
  gateway.py          # complete / complete_json / stream
  routing.py          # task profile → provider order
  budgets.py          # daily free caps + Anthropic token/USD
  policy.py           # llm_allowed() / FORCE_RULES / DEMO visitor
  prompts/            # {name}/v{N}.md + sha256 helper
  schemas/            # Pydantic models for triage/insights
  providers/
    base.py
    gemini.py
    groq.py
    ollama.py
    anthropic.py      # gated only
    fake.py           # hermetic
    rules.py          # triage fail-closed
obs/
  tracing.py          # OTel-compatible + JSONL
```

Provider SDKs **only** under `llm/providers/` (D-024).

### Interfaces

```python
complete(task: TaskProfile, messages: list[Message], *, max_tokens: int, ...) -> CompletionResult
complete_json(task, messages, schema: type[BaseModel], ...) -> T  # native JSON + Pydantic; 1 repair retry
stream(task, messages, ...) -> Iterator[StreamEvent]  # token deltas; fake-tested in B2
```

### Routing / failover

- Default order: `gemini → groq → ollama → rules|soft_fallback` (task-dependent).
- Anthropic **never** in default list.
- On 429: honor `Retry-After` (and provider headers); backoff; then next provider.
- On 5xx/timeout: next provider; circuit open N minutes per provider (**recommend N=5**, env-tunable).
- Timeouts: hard client timeout (recommend **30s** complete / **10s** connect) — fixes C-04.

### Budgets

- Env daily caps per free provider (req + tokens); persist counters via `LlmCall` aggregates or Redis-less DB query for UTC day.
- Anthropic: `OPSPILOT_ANTHROPIC_ENABLED` default false; allowlist tasks (`leaderboard`, `judge_calibration`, `demo_quality` — **not** `ask`); remaining **tokens AND USD**; pre-call deny; post-call debit from `usage`; budget 0 / disabled → **never construct client**.

### Structured outputs (D-013)

Provider-native schema/mode → Pydantic validate → **one** repair retry with validation errors in prompt → fail closed (rules for triage; soft fallback for ask/evening/insights).

### Prompt versioning

`llm/prompts/{task}/v{N}.md`; sha256 → `LlmCall.prompt_version` `char(64)`.

### `llm_allowed()` (fixes C-01)

Single policy used by **every** site:

1. If `OPSPILOT_FORCE_RULES` truthy → no remote LLM (rules / soft).
2. If tests/CI markers or `OPSPILOT_LLM_DISABLE=1` → same.
3. If visitor/DEMO path and task=`ask` → free providers only; Anthropic forbidden.
4. Else route via gateway.

### Fake provider

Deterministic fixtures keyed by task; writes `LlmCall` rows; used in unit/API tests.

### Streaming scope recommendation

**Implement `stream()` + fake provider tests in B2; do not ship FE SSE or `/ask/stream` UI until B5.** Optionally add a thin async route stub behind a feature flag for smoke only — default off. Matches D-010 (async HTTP when streaming) without pulling B5 agent chrome.
