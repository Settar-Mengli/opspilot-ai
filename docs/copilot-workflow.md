# Copilot Workflow

## Purpose

Define a consistent, auditable workflow for AI-assisted development in this repository.

## Working Rules

1. Explain before editing files.
2. Keep changes small and within approved scope.
3. Validate changes with relevant tests or provide a deferral reason.
4. Update progress and decisions when applicable.

## Required Step Report

After each coding step, include:

- What changed
- Files created or edited
- How to run
- How to test
- Recommendations for improvement

## Change Types

- Governance/docs change
- Behavior change
- Architecture change

## Required Documentation Updates

- Always update PROGRESS.md after completed steps.
- Update docs/decisions.md for architecture-level decisions.
- Keep docs consistent with glossary terms.

## Safety Rules

- Do not revert unrelated user changes.
- Do not use destructive git commands unless explicitly requested.
- Do not introduce paid dependencies in early milestones.

## Handoff Rules

- End each step with next actionable task.
- Identify open risks and assumptions.
