# AI Memory Policy

## Purpose

This directory may store concise AI-assistant context notes for continuity across sessions.

## Authority Rules

- AI memory is non-authoritative.
- AI memory cannot override decisions in docs/decisions.md.
- If conflicts exist, docs/decisions.md and docs/milestones.md take precedence.

## Allowed Content

- Session context summaries
- Temporary reminders
- Open questions to revisit

## Forbidden Content

- Secrets, tokens, credentials, or private data
- Canonical architecture decisions
- Final scope definitions

## Maintenance

- Keep notes short and current.
- Remove stale entries regularly.
- Promote stable decisions into docs/decisions.md, not this directory.
